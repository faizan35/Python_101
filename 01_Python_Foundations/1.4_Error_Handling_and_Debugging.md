## ✅ 1. Built-in Exceptions

Common exceptions:

```python
# ZeroDivisionError
print(5 / 0)

# ValueError
int("abc")

# KeyError
d = {"a": 1}
print(d["b"])

# IndexError
lst = [1, 2]
print(lst[5])

# TypeError
print("3" + 3)
```

## ✅ 2. try / except / else / finally

```python
try:
    x = int(input("Enter a number: "))
    result = 10 / x
except ZeroDivisionError:
    print("Can't divide by zero")
except ValueError:
    print("Invalid input")
else:
    print("Result is", result)
finally:
    print("This block always runs")
```

- `try`: wrap risky code
- `except`: catch exceptions
- `else`: runs if no exception
- `finally`: always runs

## ✅ 3. Raising Custom Exceptions

```python
def divide(a, b):
    if b == 0:
        raise ValueError("b cannot be zero")
    return a / b

print(divide(10, 2))
print(divide(5, 0))
```

You can define your own exception classes:

```python
class NegativeAgeError(Exception):
    pass

def set_age(age):
    if age < 0:
        raise NegativeAgeError("Age cannot be negative")

set_age(-5)
```

## ✅ 4. Debugging with `pdb`

### Using `pdb.set_trace()`

```python
import pdb

x = 10
pdb.set_trace()
y = x + 5
print(y)
```

Basic `pdb` commands:

- `n`: next line
- `c`: continue
- `q`: quit
- `p variable`: print variable

---

### VSCode / PyCharm breakpoints

- Click next to the line number to set a breakpoint.
- Run with debugger (`F5` in VSCode).
- Inspect variables, step over/in/out, view call stack.

## ✅ 5. Logging Basics

Instead of using `print()` for debugging or reporting errors, use logging.

```python
import logging

logging.basicConfig(level=logging.INFO)

logging.debug("This is a debug message")
logging.info("This is info")
logging.warning("This is a warning")
logging.error("This is an error")
logging.critical("This is critical")
```

You can configure it to log to files, show timestamps, and more:

```python
logging.basicConfig(
    filename="app.log",
    level=logging.ERROR,
    format="%(asctime)s - %(levelname)s - %(message)s"
)
```
