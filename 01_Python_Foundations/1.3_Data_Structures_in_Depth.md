# 1. Strings

### Slicing

```python
s = "hello world"
print(s[0:5])   # hello
print(s[-5:])   # world
print(s[::-1])  # reverse
```

### 📌 Immutability

```python
s = "hello"
# s[0] = 'H'  # ❌ Error: strings are immutable
s = "H" + s[1:]  # ✅ workaround
```

## ✅ 2. Lists

```python
fruits = ['apple', 'banana', 'cherry']
fruits.append('orange')
fruits.insert(1, 'kiwi')
fruits.remove('banana')
print(fruits)
```

### 📌 Nested Lists

```python
matrix = [[1, 2], [3, 4]]
print(matrix[1][0])  # 3
```

---

## ✅ 3. Tuples

```python
t = (10, 20, 30)
# t[0] = 99  # ❌ Error: immutable

# Unpacking
a, b, c = t
print(a, b, c)
```

Tuples are preferred for fixed-length, immutable sequences.

---

## ✅ 4. Sets

```python
s1 = {1, 2, 3}
s2 = {3, 4, 5}

print(s1 | s2)   # union
print(s1 & s2)   # intersection
print(s1 - s2)   # difference

s1.add(99)
s1.remove(1)
print(s1)
```

Sets are unordered and automatically remove duplicates.

## ✅ 5. Dictionaries

```python
person = {'name': 'Faizan', 'age': 25}

# Access
print(person['name'])

# Add/update
person['city'] = 'Mumbai'
person['age'] = 26

# Iterate
for key, value in person.items():
    print(key, value)
```

## ✅ 6. Comprehensions

### 📌 List comprehension

```python
squares = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]
```

### 📌 Dict comprehension

```python
nums = [1, 2, 3]
squared_map = {x: x**2 for x in nums}
```

### 📌 Set comprehension

```python
evens = {x for x in range(10) if x % 2 == 0}
```

### 📌 Nested list comprehension

```python
matrix = [[1, 2], [3, 4]]
flattened = [num for row in matrix for num in row]  # [1, 2, 3, 4]
```
