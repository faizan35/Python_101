# 1.2 Python Syntax and Core Constructs

## 1. Variables, Expressions, Statements

### Variables

```python
name = "anyname"
age = 25
pi = 3.14
```

### Expressions

```python
area = pi * (5 ** 2)  # 78.5
```

### Statements

```python
x = 10
y = 20
z = x + y
```

## 2. Input / Output and String Formatting

### Basic I/O

```python
name = input("Enter your name: ")
print("Hello,", name)
```

### String formatting

```python
# Old style
print("Hello %s, you are %d years old" % ("Faizan", 25))

# format() method
print("Hello {}, you are {} years old".format("Faizan", 25))

# f-string (Python 3.6+)
name = "Faizan"
age = 25
print(f"Hello {name}, you are {age} years old")
```

## 3. Data Types

```python
a = 10             # int
b = 3.14           # float
c = True           # bool
d = "Hello world"  # str

print(type(a), type(b), type(c), type(d))
```

## 4. Conditionals

```python
x = 15

if x > 10:
    print("Greater than 10")
elif x == 10:
    print("Equal to 10")
else:
    print("Less than 10")
```

## 5. Loops

### `for` loop with `range`

```python
for i in range(5):
    print(i)
```

### `while` loop

```python
count = 0
while count < 5:
    print(count)
    count += 1
```

### `break`, `continue`

```python
for i in range(10):
    if i == 5:
        break
    if i % 2 == 0:
        continue
    print(i)  # prints odd numbers less than 5
```

## 6. Functions

```python
def greet(name):
    return f"Hello {name}"

msg = greet("Faizan")
print(msg)
```

### With parameters and return

```python
def add(a, b):
    return a + b

print(add(3, 4))  # 7
```

## 7. Basic Recursion

```python
def factorial(n):
    if n == 0:
        return 1
    return n * factorial(n - 1)

print(factorial(5))  # 120
```
