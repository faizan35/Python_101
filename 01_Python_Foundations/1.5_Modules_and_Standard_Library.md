## ✅ 1. Writing Custom Modules

### Step-by-step:

1. **Create a file** called `mymath.py`:

```python
# mymath.py
def add(a, b):
    return a + b

def square(x):
    return x * x
```

2. **Use it in another file**:

```python
# main.py
import mymath

print(mymath.add(2, 3))      # 5
print(mymath.square(4))      # 16
```

## ✅ 2. Import Styles

### Different ways to import:

```python
import math              # import whole module
from math import sqrt    # import specific function
from math import *       # import everything (not recommended)
import math as m         # alias
```

### Best practice:

- Use explicit imports: `from math import sqrt`
- Alias long modules: `import itertools as it`

## ✅ 3. Key Standard Modules

---

### 📌 `math`

```python
import math

print(math.sqrt(16))      # 4.0
print(math.floor(3.9))    # 3
print(math.factorial(5))  # 120
print(math.pi)            # 3.141...
```

---

### 📌 `random`

```python
import random

print(random.randint(1, 10))       # Random int
print(random.choice(['a', 'b']))   # Random element
random.shuffle([1, 2, 3, 4])       # Shuffle list
```

---

### 📌 `datetime`

```python
from datetime import datetime, timedelta

now = datetime.now()
print(now.strftime("%Y-%m-%d %H:%M:%S"))

yesterday = now - timedelta(days=1)
print(yesterday)
```

---

### 📌 `collections`

```python
from collections import Counter, defaultdict, namedtuple

# Counter
c = Counter('banana')
print(c)

# defaultdict
d = defaultdict(int)
d['a'] += 1
print(d['a'], d['b'])  # 1 0

# namedtuple
Point = namedtuple('Point', 'x y')
p = Point(1, 2)
print(p.x, p.y)
```

---

### 📌 `itertools`

```python
import itertools as it

# Infinite counter
# for i in it.count(10, 2): print(i) → infinite loop

# Cartesian product
for a in it.product([1, 2], ['a', 'b']):
    print(a)

# Combinations
for c in it.combinations([1, 2, 3], 2):
    print(c)
```
