## ✅ 1. Reading and Writing Text/Binary Files

### 📌 Text files

```python
# Write to file
with open("notes.txt", "w") as f:
    f.write("Hello, Faizan\nThis is Python.")

# Append
with open("notes.txt", "a") as f:
    f.write("\nAppending this line.")

# Read entire file
with open("notes.txt", "r") as f:
    content = f.read()
    print(content)

# Read line-by-line
with open("notes.txt", "r") as f:
    for line in f:
        print(line.strip())
```

### 📌 Binary files

```python
# Write binary
with open("data.bin", "wb") as f:
    f.write(b'\x00\x01\x02\x03')

# Read binary
with open("data.bin", "rb") as f:
    data = f.read()
    print(data)
```

## ✅ 2. Working with CSV and JSON

### 📌 CSV (Comma-Separated Values)

```python
import csv

# Writing CSV
with open("data.csv", "w", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["Name", "Age"])
    writer.writerow(["Faizan", 25])

# Reading CSV
with open("data.csv", "r") as f:
    reader = csv.reader(f)
    for row in reader:
        print(row)
```

### 📌 JSON

```python
import json

data = {"name": "Faizan", "age": 25}

# Write JSON
with open("user.json", "w") as f:
    json.dump(data, f)

# Read JSON
with open("user.json", "r") as f:
    loaded = json.load(f)
    print(loaded)
```

## ✅ 3. `os`, `pathlib`, `shutil`, `glob`

### 📌 `os` module

```python
import os

print(os.getcwd())              # Current dir
os.mkdir("new_folder")          # Create dir
os.rename("notes.txt", "note.txt")
os.remove("note.txt")           # Delete file
```

### 📌 `pathlib` (modern, OOP-style path handling)

```python
from pathlib import Path

p = Path("new_folder")
p.mkdir(exist_ok=True)

file_path = p / "file.txt"
file_path.write_text("Pathlib content")
print(file_path.read_text())
```

### 📌 `shutil` (file operations)

```python
import shutil

shutil.copy("data.csv", "data_backup.csv")
shutil.move("data.csv", "new_folder/data.csv")
shutil.rmtree("new_folder")  # Recursively delete
```

### 📌 `glob` (pattern matching)

```python
import glob

print(glob.glob("*.txt"))     # All .txt files in current dir
print(glob.glob("**/*.py", recursive=True))  # All .py files recursively
```
